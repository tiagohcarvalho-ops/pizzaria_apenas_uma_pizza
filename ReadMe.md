# 💻 Apenas Uma Pizza

Projeto acadêmico desenvolvido como trabalho de conclusão de semestre.
O sistema consiste em um site estático para uma pizzaria fictícia chamada Apenas Uma Pizza.

# ⚙️ Tecnologias Utilizadas

HTML5

CSS3

JavaScript

# 📋 Objetivo do Projeto

O objetivo do projeto é praticar conceitos de desenvolvimento web front-end, utilizando estruturação com HTML, estilização com CSS e interatividade com JavaScript.

# 🖥️ Funcionalidades

Página inicial da pizzaria

Cardápio de pizzas

Layout responsivo

Interações básicas com JavaScript
